- **Нет официальных HEX-кодов бренда** — у нас оценка с растра, не из брендбука.
- **Нет монохромной версии** — для светлого/тёмного фона, для печати, для favicon в большом размере.

## Тип сайта: КАТАЛОЖНЫЙ B2B (важно!)

Наш сайт — **каталожный B2B-сайт промышленного оборудования**, не корпоративно-имиджевый и не лендинг. Структура (см. CLAUDE.md):

- ~140 карточек товаров
- 29 категорий + подкатегорий
- 19 страниц «в наличии»
- ~170 страниц «выполненных проектов»

**Это значит, что главные дизайн-паттерны и UX-решения — каталожные.** Когда смотрим референс, оцениваем не «красоту главной», а:

| Каталожный паттерн | Что должно быть сильно |
|---|---|
| **Hub-страница каталога** | Сетка категорий с фото + понятная иерархия, навигация в 1–2 клика до любого SKU |
| **Страница категории** | Таблица/сетка моделей с возможностью сравнения по тех. параметрам |
| **Карточка продукта** | Фото-галерея + тех. характеристики таблицей + варианты комплектации + datasheet PDF + СТА «Запросить КП» |
| **Фильтры и сравнение** | Фильтрация по мощности / тонажу / типу металла; механика «Сравнить» |
| **Документация** | Скачивание PDF (паспорт, схема, сертификаты) — first-class элемент, не «зарытый где-то» |
| **Кейс / проект как доказательство** | Связка «продукт → где он работает» (мост между каталогом и страницами `/equipment/`) |
| **CTA в hero и в карточке** | «Запросить КП», «Связаться с инженером», «Получить расчёт» — не одинокая «Контакты» в хедере |

Поэтому референсы ниже отобраны **в первую очередь по силе каталожного паттерна**, не просто по эстетике главной.

### 🎯 Стратегический вывод по RU-сегменту

1. **9 из 10 прямых RU-конкурентов находятся на уровне 4–5/10.** Это уровень WordPress-шаблона 2014–2018 годов с минимальной кастомизацией.
2. **Уже на уровне 7/10 МТПК становится визуально лучшим российским производителем в сегменте.** Это легко-достижимая планка с правильным якорем + хорошим продакт-фото.
3. **Целиться надо не в RU-уровень, а в международный (TRUMPF, DMG MORI, ECM).** RU-конкуренты — это «дно для отстройки», международные — «потолок к которому идём». Если попадём между ними (~7.5–8.5/10) — будем визуально доминировать в RU и не выпадать в B2B-экспорте.
4. **Это сильный аргумент для бизнес-кейса A/B-теста.** Текущий uralinduktor.ru на уровне ~4/10 (типичный WordPress B2B). Прыжок до 8/10 даёт ожидаемый рост конверсии в заявку.

## Открытые вопросы пользователю

### По бренду / логотипу
1. **🔴 КРИТИЧНО: Векторный SVG/AI/CDR-оригинал логотипа.** Текущий PNG (147×35) подключён в прототип, но для production непригоден — на retina и больших экранах будет мыло. Замена займёт 30 секунд, как только пришлёшь файл.
2. **Есть ли брендбук** с официальными HEX-кодами, охранными полями, типографикой бренда? Или мы с нуля задаём дизайн-систему?
3. **Готов ли заказчик к лёгкому обновлению логотипа** (перерисовка в вектор с уточнением пропорций, если оригинала нет)? Или знак священен 1-в-1?
4. **Должно ли «МТПК» появляться рядом с «УРАЛ ИНДУКТОР»** в шапке нового сайта (как в footer-варианте) или только «УРАЛ ИНДУКТОР»?

### По продакт-фото
5. **Есть ли у заказчика качественные фото оборудования** (студийные, в цеху, в работе)? Это критично — без хороших фото ни TRUMPF, ни DMG MORI стиль не работает.
6. Если фото плохие/нет — закладывать ли в план **фото-сессию на производстве** или работать только с тем, что есть?

### По языкам и аудитории
7. **Только русский** или нужна **английская версия** (экспорт)?
8. **Кто целевой посетитель сайта** на 80% — главный энергетик завода? директор по производству? закупщик? технолог? (От этого зависит плотность, тон копирайта, что выносим в hero.)

### По объёму первой итерации
9. **Делаем сразу все ~406 страниц** или **MVP-набор** на запуск (главная + 5–7 ключевых категорий каталога + контакты + 3 кейса), а остальное доливаем итеративно?
