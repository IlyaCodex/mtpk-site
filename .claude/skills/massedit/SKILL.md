Массовые изменения НЕ делаются руками по одному файлу. Только скриптом.
1. Собери список затронутых файлов (grep/find), покажи мне: сколько файлов,
   что именно меняется, 1 пример «до → после». ЖДИ моего «ок»
   (массовое = труднообратимое, это блокирующая точка).
2. git commit ДО правки (точка отката).
3. Правка python-скриптом (сохрани его в scripts/oneoff/, имя по смыслу).
4. Проверка: 3 случайные страницы из списка — скриншоты (scripts/shot.sh),
   посмотри глазами. Партиалы не задеты? sync-partials.py --check.
5. git commit ПОСЛЕ + отчёт: сколько файлов изменено, что проверено.
