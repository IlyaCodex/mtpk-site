Массовые изменения НЕ делаются руками по одной странице. Только скриптом.
Контент — в базе платформы (platform/, локально); правим через API контент-сервиса
(/admin/v1/…, заголовок X-Admin-Token) — кеш, поиск и сайт обновятся сами.
1. Собери список затронутых страниц (запрос к API или базе), покажи мне: сколько страниц,
   что именно меняется, 1 пример «до → после». ЖДИ моего «ок»
   (массовое = труднообратимое, это блокирующая точка).
2. Точка отката: cd platform && npm run checks -- --save (эталон сайта) + выгрузка
   затронутых страниц (GET /admin/v1/pages/:id) в platform/tools/checks/report/backup-<дата>.json.
3. Правка скриптом (platform/scripts/oneoff/<имя-по-смыслу>.ts, запуск npx tsx).
4. Проверка: npm run checks — HTML отличается только там, где задумано; 3 случайные
   страницы — снимки (npm run checks -- --visual --only=…), посмотри глазами.
5. git commit скрипта + отчёт: сколько страниц изменено, что проверено.
