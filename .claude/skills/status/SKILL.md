Покажи коротко:
1. git status -s (некоммиченное) + git log --oneline -5.
2. PLAN.md: текущий этап (первый с незакрытыми пунктами), что сделано/что следующее.
3. Открытые вопросы к Евгению, если записаны в PLAN.md.
4. Одной строкой: следующий шаг и команда (/task, /fix, /page, /ship).
Прогресс считай ТОЛЬКО по отметкам в PLAN.md — пересказам в других файлах не верь.
