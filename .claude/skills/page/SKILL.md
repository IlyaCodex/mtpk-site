1. СНАЧАЛА уточни у меня: адрес, вложенность, привязка к меню (если не сказано).
2. Определи тип по docs/page-types/README.md, открой соответствующий T0x.md —
   это источник правды по секциям страницы.
3. Контент бери из site/<путь>/ (слепок старого сайта: content.md + INDEX.md + images/)
   или от меня.
4. Создание — в платформе (локально, админка http://127.0.0.1:3300):
   - категория / подкатегория / товар каталога — «Каталог продукции» → «Добавить …»
     (страница создаётся черновиком по образцу соседних, адрес — из названия);
   - остальные страницы — «Все страницы» → «Новая страница» (или POST /admin/v1/pages).
   Формы, преимущества, партнёры — общие блоки (Форма «Подбор и расчёт», «Лучшее
   предложение», «Преимущества»…), их HTML не копировать.
5. Соблюдай: адрес со слешем на конце и = хлебным крошкам, style.md (дизайн),
   picture.md (картинки — в медиатеку).
6. Запиши страницу в structura.md (адрес, тип, статус 🟡).
7. Проверка: страница на http://127.0.0.1:3200/<адрес>, снимки —
   cd platform && npm run checks -- --save --visual --only=<адрес> (эталон новой страницы),
   посмотри снимки глазами (platform/tools/checks/baseline/shots).
8. Опубликуй (статус «На сайте»), git commit документов + отметка в PLAN.md.
   Скажи, что готово и что дальше.
