Вход от Евгения: страница (URL или имя) + блок + что не так.
Сайт — платформа platform/ (данные в Postgres, локально: сайт http://127.0.0.1:3200,
админка http://127.0.0.1:3300). Выкладки нет — работаем только локально.
1. Найди, где живёт блок:
   - содержимое страницы — её блоки в базе (админка «Каталог продукции» / «Все страницы»,
     или API контент-сервиса GET /admin/v1/pages?search=…);
   - общая секция (форма заявки, преимущества, партнёры) — React-компонент
     platform/packages/ui/src/blocks, у товаров — шаблон категории (карточка категории
     в админке, «Общие секции под товарами»);
   - шапка, меню, подвал — админка «Шапка, меню, контакты».
   Неоднозначно — покажи кандидатов, спроси.
2. До правки: cd platform && npm run checks -- --save --visual --only=<адрес>
   (если правка общая — без --only: эталон HTML всех страниц).
3. Правка: содержимое — в админке или через API; вёрстка — в компоненте; цвета и отступы —
   только из style.md.
4. После: npm run checks -- --visual --only=<адрес> (общая правка — ещё и npm run checks
   по всем страницам). Снимки отличий — platform/tools/checks/report/visual, посмотри глазами.
   Поехало что-то кроме целевого блока → чини, повторяй до чистого результата.
5. git commit кода (адресный git add). Если правка по техдолгу всплыла попутно —
   не чини молча: запиши в PLAN.md раздел техдолга и скажи мне.
