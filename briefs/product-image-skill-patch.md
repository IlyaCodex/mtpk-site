# Патч скила /product-image — применить сессией Claude Code

> Причина (2026-06-05): Евгений дал задачу свободным текстом («перерисовать
> картинки здесь… исходники здесь…») — скил не сработал, сессия импровизировала.
> Диагноз: (1) `disable-model-invocation: true` запрещает автозапуск скила,
> (2) в скиле нет батч-режима «категория + исходники со старого сайта».
> Задача сессии: внести в `.claude/skills/product-image/SKILL.md` правки 1–3 ниже,
> ничего больше в скиле не меняя. Проверка — раздел «Тест» внизу.

## Правка 1. Шапка (frontmatter) — заменить целиком

Было:

```
---
name: product-image
description: Перерисовать товарную картинку в цех-канон (v3) и разложить в прод
disable-model-invocation: true
---
```

Стало (убран disable-model-invocation, описание с триггерами):

```
---
name: product-image
description: Перерисовать/заменить товарные картинки в цех-канон (v3) — один товар, категория или раздел целиком; исходники из site/, ФОТО/ или с живого uralinduktor.ru. Триггеры: «перерисуй/замени картинки», «картинки раздела/категории», «исходники на старом сайте».
---
```

## Правка 2. Сразу после шапки добавить

```
> ЛЮБАЯ задача про товарные картинки идёт ТОЛЬКО по этому скилу (правило #9
> CLAUDE.md). Свободная формулировка Евгения = тоже этот скил, не импровизация.
> Цель — категория/раздел → раздел «БАТЧ: категория целиком» внизу.
```

## Правка 3. Раздел «Батч (выравнивание нарушителей…)» дополнить вторым режимом

Добавить ПЕРЕД существующим батч-разделом (его не удалять — это режим Б):

```
## БАТЧ: категория целиком (режим А)

Вход: целевая категория нового сайта + источник (категория старого сайта /
site/ / папка). Пример запроса Евгения: «перерисовать картинки на
new.uralinduktor.ru/products/<категория>/, исходники по названиям на
uralinduktor.ru/products/<категория>/, внутри карточек тоже заменить».

1. МАППИНГ-ТАБЛИЦА ДО ГЕНЕРАЦИИ. Товары категории = подпапки
   astro/src/raw-pages/products/<категория>/. Исходники: site/<...>/images/,
   а если категории нет в слепке — скачать страницы живого uralinduktor.ru
   (curl) и вытащить картинки товаров. Маппинг по слагам/названиям.
2. ОДИН блокирующий вопрос на весь батч: показать Евгению таблицу
   «товар → исходник → целевой файл → где заменится (grep по имени)».
   После «ок» — без вопросов по каждому товару.
3. Замена = перезапись под ТЕМ ЖЕ именем файла (card-*.jpg): одно имя живёт
   в хабе, на странице товара и в корне каталога — заменится везде, HTML не
   трогать. ОБЯЗАТЕЛЬНО перегенерить WebP-сосед (иначе браузеры с Accept:
   webp продолжат видеть старую). Hero категории — тоже в батч.
4. По каждому товару: шаги 1–4 скила (промт v3, самопроверка). Дефект после
   одной повторной итерации → пометить в отчёте, идти дальше, батч не стопорить.
5. Финал: прод-конвейер на все файлы (шаг 5), picture.md, скриншоты хаба +
   2 товарных страниц, отчёт-таблица «сделано/пропущено», ОДИН git-коммит.
```

## Тест после правок

1. Свободная фраза «надо перерисовать картинки в категории X, исходники на
   старом сайте» в новой сессии → сессия открывает скил (не импровизирует)
   и начинает с маппинг-таблицы.
2. `/product-image <товар> <исходник>` — одиночный режим работает как раньше.
