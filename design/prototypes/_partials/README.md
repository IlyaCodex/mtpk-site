# Партиалы прототипов — справочно

Шапка, подвал и мобильное меню здесь — HTML-прототипы времён сайта на Astro. **Сайт их не использует**,
правки в этих файлах ни на что не влияют.

На сайте (платформа `platform/`) это React-компоненты — одни на все страницы, включая статьи Практикума:

| Что | Где |
|---|---|
| Шапка и мегаменю | `platform/apps/web/src/components/layout/Header.tsx` |
| Мобильное меню | `platform/apps/web/src/components/layout/Drawer.tsx`, стили — `platform/apps/web/public/css/mobile-fixes.css` (раздел 5) |
| Подвал | `platform/apps/web/src/components/layout/Footer.tsx` |
| Пункты меню, подменю, контакты, подвал | админка «Шапка, меню, контакты» (данные, без правки кода) |

Добавить пункт или подпункт меню — в админке. Новый вид элемента (другой тип подменю и т. п.) — правка компонента.
