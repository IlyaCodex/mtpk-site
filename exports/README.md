# Выгрузки адресов

Списки URL для отправки на переобход в Яндекс.Вебмастере и Google Search Console.

## Что лежит

- `urls-<дата>.xlsx` — лист «Адреса» (URL · раздел · заголовок, с фильтром
  и закреплённой шапкой) и лист «Сводка» со счётчиком по разделам.
- `urls-<дата>.txt` — тот же список простым текстом, по адресу в строке:
  удобно вставлять в поле «Переобход страниц» без Excel.

## Как пересобрать

```bash
cd astro && npm run build     # выгрузка берётся из dist — то, что реально на проде
cd .. && python scripts/export-urls.py
```

Скрипт [`scripts/export-urls.py`](../scripts/export-urls.py) обходит `astro/dist`,
берёт разделы из списка `SECTIONS` в начале файла и выбрасывает страницы,
закрытые `noindex` или отсутствующие в `sitemap.xml`, — такие слать на переобход
бессмысленно. Нужен другой набор разделов — правится `SECTIONS`.

## Про квоты

Яндекс.Вебмастер лимитирует переобход (порядка сотни адресов в сутки на сайт,
точное число показывает сам кабинет). Список из нескольких сотен адресов
отправляют частями; в первую очередь — хабы и категории, за ними карточки.
