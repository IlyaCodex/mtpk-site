# Шпаргалка: ситуация → команда (сайт Уралиндуктор)

Каждая команда — свежая сессия. Ценность — в файлах (PLAN.md, structura.md, git),
сессия — расходный материал.

| Ситуация | Что делать |
|---|---|
| Продолжаем работу по плану | `/task` — возьмёт следующий пункт PLAN.md |
| «Поправь вот это на странице X» | `/fix` + скажи: URL/страница, блок, что не так |
| Нужна новая страница | `/page` + скажи: URL, куда в меню |
| Нужна картинка | `/imagegen` + скажи: для какой страницы/блока |
| Поменять что-то на многих страницах | `/massedit` — скриптом, с твоим «ок» |
| Выложить на прод | `/ship` — по чек-листу с граблями |
| Потерялся | `/status` |
| Верстка поехала после правки | Сессия обязана была поймать скриншотом; скажи `/fix` повторно — и git откатит: `git diff` / `git checkout -- <файл>` |
| Claude фантазирует стиль картинки | Скил /imagegen требует эталоны из picture/ — напомни: «по канону /imagegen» |
| Claude дважды сделал не то | `/clear`, новая сессия, точнее промпт |
| Нашёл косяк техдолга | Скажи сессии: «запиши в PLAN.md» (этап 4/9) — и забудь до /task |

## Как объяснять «что и где» (адресный язык)

Формат: **URL страницы + имя блока + что не так**.
Пример: «На `/products/drobemetnoe-oborudovanie/` в блоке карточек подкатегорий
третья карточка — картинка вылезает за рамку».
Имена блоков — из docs/page-types/T0x.md (hero, leadgen, карточки, баннер...).
Не знаешь имя блока — скажи «блок после шапки, с синим фоном» + URL, сессия найдёт.

## Git (страховка)

- Коммит после каждой задачи — делают скилы сами.
- Откат файла: `git checkout -- <путь>` · посмотреть что менялось: `git log --oneline`
- ФОТО/ в git не входит (7.8ГБ сырья) — бэкапь отдельно.
