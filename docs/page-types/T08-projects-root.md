## Источник данных

Все 170+ проектов читаются из `astro/public/js/projects-data.js` (массив объектов с координатами, описанием, картинкой, URL). На клиенте:
- карта рисует точки (`projects-map.js`),
- сетка рендерит карточки с пагинацией.

## SEO

- `<h1>` в hero.
- `<h2>` на карте, фильтре, сетке.
