# T07 · Проект / кейс

**URL-паттерн:** `/proekty/<slug>/`
**Источник:** `astro/src/raw-pages/proekty/<slug>/body.html` + `meta.json`
**Кол-во страниц:** ~170

## Назначение

Карточка реализованного кейса: что именно было поставлено, куда, фото с площадки. Один лёгкий шаблон на всех — большой объём, поэтому страница максимально упрощена.

## Карта блоков

| # | Блок | Класс | Обязательно? |
|---:|---|---|---|
| 1 | Hero (тёмный, фото проекта) | `.cat-hero` | ✅ |
| 2 | Описание проекта (что поставлено, куда, когда) | `.project-body` | ✅ |
| 3 | Галерея фото | `.project-gallery` | ✅ |
| 4 | ТТХ оборудования | `.project-specs` | опц. |
| 5 | Best-offer | `<!--C:best-offer-->` | опц. |

## Поиск

Страницы проектов **НЕ индексируются** в Pagefind (внутренний поиск). Видно в `[...slug].astro`:
```js
const isProject = slug.startsWith('proekty');
const searchIndex = !isProject;
```
SEO-индексация (Я.Вебмастер) при этом сохраняется через canonical + sitemap.

## Карта проектов

Все проекты также отображаются как точки на карте на главной странице (Yandex Maps, см. `astro/public/js/projects-map.js` + `projects-data.js`).

## Чек-лист

- [ ] 1+ фото в галерее.
- [ ] Описание из 2-3 параграфов: что, куда, когда, какой результат.
- [ ] Координаты для карты в `projects-data.js`.
- [ ] Запись в `structura.md` — НЕ требуется (т.к. ~170 однотипных).
