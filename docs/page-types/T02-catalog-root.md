# T02 · Корень каталога

**URL:** `/products/`
**Источник:** `astro/src/raw-pages/products/body.html` + `meta.json`
**Кол-во страниц:** 1

## Назначение

Полный индекс каталога: все 12 разделов с их категориями (если есть). SEO-якорь по широким запросам, навигация для пользователей, кто пришёл с боковой ветки и хочет посмотреть «всё, что есть».

## Карта блоков

| # | Блок | Класс | Обязательно? |
|---:|---|---|---|
| 1 | Hero (тёмный, короткий) | `.cat-hero` | ✅ |
| 2 | 12 секций по разделам | `<section class="cat-index">` × 12 | ✅ |
| 3 | Best-offer | `<!--C:best-offer-->` | опц. |

## Структура секции раздела (`.cat-index`)

```html
<section class="cat-index">
  <div class="container">
    <div class="cat-index__head">
      <h2 class="cat-index__title">Название раздела <em>акцент</em></h2>
      <a class="cat-index__all" href="/products/<раздел>/">Раздел&nbsp;целиком →</a>
    </div>
    <div class="scard-grid">
      <a class="scard" href="/products/<раздел>/<категория>/">
        <div class="scard__cover" style="background-image: url('/img/card-...png')"></div>
        <div class="scard__body">
          <h3 class="scard__title">Название категории с предметным якорем</h3>
          <div class="scard__meta"><span>N моделей</span><span class="scard__meta-arrow">→</span></div>
        </div>
      </a>
      <!-- ... все категории раздела -->
    </div>
  </div>
</section>
```

## Правила контента

1. **Все категории должны быть представлены.** Если в разделе 9 категорий — выводим 9 карточек.
2. **Заголовок карточки содержит предметный якорь:** «Печи для…», «Дробемёт…», «Ковш…», «Чиллеры…», «Градирни…». Без якоря — допускается только для технологических разделов (ЛВМ, ЛГМ, ХТС, ПГС), где якорь = «Оборудование / Линии ЛВМ».
3. **Картинки** — те же `card-*.png/jpg`, что в `teaser-card` на странице раздела (T03). Не использовать hero подкатегории.
4. **Если у раздела нет категорий** (как у induktsionnye-nagrevateli, oborudovanie-lvm и т.п.) — выводим **одну** карточку с заголовком в формате «Слово-якорь — описание» и ссылкой на сам раздел.

## SEO

- `<h1>` в hero — «Полный каталог».
- `<h2>` × 12 — по одному на каждый раздел.
- `<h3>` — название категории внутри карточки.

## CSS

Базовый блок наследуется от `induktsionnye-plavilnye-pechi`. Override (`.cat-index`, `.scard`) добавлен в `inline_styles[1]` в `meta.json`. Принудительно задаёт `body { background: #FFFFFF }` и тёмные цвета текста с `!important`.

## Пример

См. live: https://uralinduktor.ru/products/

## Связанные

- При добавлении новой категории в любом разделе — обязательно добавить карточку сюда.
- При смене картинки `card-*` на хабе раздела — обновить и тут (одни и те же файлы).
