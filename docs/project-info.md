### Наследие WordPress

- Дубли ru/en слагов: `/contact/`↔`/kontakty/`, `/leasing/`↔`/lizing/`,
  `/service/`↔`/uslugi/`, `/o-company/`↔`/o-kompanii/`. Предложение: оставить
  русские, английские → 301.
- Слаги с опечатками (`inductionye-...`, `drobometnii-...`): сохраняем как есть
  (требование), фиксируем как техдолг.
- ID-как-слаг (`/products/.../15132/`): сохраняем.
- Дубли категорий с `-2`: сохраняем, документируем.
