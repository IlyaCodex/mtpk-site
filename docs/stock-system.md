# Подсистема «Наличие на складе»

> Платформа `platform/` (с 07.10.2026). Описание конфига `astro/data/stock.config.json` и скриптов
> сборки эпохи Astro — в истории git этого файла. Обновлено: 2026-10-09 (типы, фото со склада, новый блок на главной).

## Что это

Один раздел админки — **«Наличие на складе»** (`/admin/stock`) — и четыре эффекта на сайте:

1. **Главная → блок «Склад и оперативные поставки»** (блок `stockShowcase`): вкладки «Оборудование» /
   «Запчасти и расходники», карусель карточек **типов** (фото, название, «Смотреть позиции ↗»), строка
   о сроках отгрузки и ссылка «Всё оборудование в наличии». Карточка ведёт на `/nalichie/?type=<метка>#stock-list`.
2. **`/nalichie/` → «Сейчас на складе»** (блок `stockList`): кнопки-фильтры по типам (тип из адреса выбирается
   сам), карточки **позиций** — фото с бейджами, значок «на весь экран» справа вверху, миниатюры
   **«Фото со склада»**, характеристики, количество и срок, «Запросить цену», «Подробнее о позиции».
3. **Каталог** — бейдж «В наличии» на карточке товара, если товар есть на складе.
4. **Страница товара** — бейдж «В наличии» и статус «отгрузка …» (срок — поле позиции, иначе «от 1 рабочего дня»).

## Данные

| Таблица | Что хранит |
|---|---|
| `content.stock_groups` | **Тип**: метка (`key`, в адресе фильтра), раздел (`kind`: `equipment` / `parts`), название, фото карточки, порядок |
| `content.stock_items` | **Позиция**: тип (`group_key`), ссылка на товар/раздел (`url`, может быть пустой), количество, срок отгрузки, своё название / фото / характеристики, **фото со склада** (`photos`: `[{src, alt}]`), примечание для себя, порядок, **скрыта на сайте** (`hidden`) |

Пустые поля позиции берутся из каталога: товар или раздел по ссылке даёт название, фото, плашку («Сталь / чугун»)
и характеристики; у страниц запчастей (их нет в таблицах каталога) — заголовок и первое фото страницы.
Ссылка на черновик каталога на сайт не выводится. Тип без позиций на сайте не показывается; фото типа
по умолчанию — фото его первой позиции. Скрытая позиция (`hidden`) остаётся в админке, но на сайт не
выводится: ни в блоках склада, ни в `/data/stock.json` (бейдж «В наличии» и срок отгрузки на странице товара);
тип, все позиции которого скрыты, тоже не показывается.

Поля из админки — простой текст: сайт сам экранирует его и ставит неразрывный пробел после предлогов.

## Как это собирается

- Контент-сервис (`services/content/src/store.ts`): `stockView()` — типы и позиции для блоков
  (`packages/content-kit/src/stock.ts` → `resolveStockView`, `resolveStockBlocks`), кладёт их в блоки
  `stockShowcase` / `stockList` при выводе страницы (как карточки каталога). `/data/stock.json` — адреса
  товаров на складе для старого скрипта бейджей в блоках «HTML как есть» (`stock-badges.js`).
- Разметка — `packages/ui/src/blocks/Stock.tsx`, стили — `site.css` (`.stock-show`, `.stock-type`) и
  `stock.css` (`.pcard__zoom`, `.pcard__photos`), поведение — модуль `apps/web/src/client/stock.ts`
  (вкладки, стрелки, фильтр), просмотр фото — `lightbox.ts` (у карточки свой набор кадров:
  `data-lightbox-group`, кадры `data-slide`).
- Сохранение в админке — `PUT /admin/v1/stock` целиком (типы и позиции). Если поменялся список товаров
  или сроки (они видны в каталоге и на страницах товаров) — пересобирается весь сайт, иначе — только
  страницы со складом (главная, `/nalichie/`).

## Как работать (админка «Наличие на складе»)

- Вкладка раздела → тип → «Добавить позицию»: тип, **оборудование на сайте** (поиск по товарам, разделам
  каталога и страницам запчастей; можно указать адрес вручную), наименование (пусто — как на странице),
  количество, срок отгрузки, фото, **фото со склада** (загрузка с компьютера или из медиатеки, папка
  `img/stock/<позиция>/`), характеристики, примечание. «Сохранить» — сразу на сайте.
- «Новый тип оборудования / запчастей»: название, раздел, фото карточки (пусто — фото первой позиции),
  метка в адресе (собирается из названия).
- Тумблер **«Показывать / Скрыта»** у позиции — убрать её с сайта, не удаляя (например, бронь или
  временно нет): позиция остаётся в списке (бледная, с отметкой «скрыта на сайте»), в заголовке типа —
  сколько скрыто. Включить обратно — тем же тумблером.
- Порядок типов и позиций — стрелками; удалить тип можно, когда в нём нет позиций.
