Смешивание · Бегуны

Смеситель чашечный (бегуны)

Область применения

Изготовление формовочной и стержневой смеси в литейном производстве.

Основные элементы оборудования

Вертикальные катки, скребки (отвалы), электропривод, выпускной люк с пневмоприводом.

Приготовление смеси

  1. Включить привод вращения катков (скребков).
  2. Загрузить сухие компоненты смеси (время перемешивания 1–2 минуты).
  3. После образования однородной массы добавить жидкие компоненты (процесс перемешивания 5–10 минут).
  4. После достижения необходимых свойств выпустить готовую смесь через выпускной люк.
